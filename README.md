# Space Invaders – Version Python (Turtle + Pygame)

Un mini-jeu Space Invaders développé en Python, utilisant **Turtle** pour l’affichage et **Pygame** pour les effets sonores.  
Le joueur contrôle un vaisseau, tire des lasers, élimine des ennemis et tente de survivre le plus longtemps possible.

## Fonctionnalités

- Déplacement fluide du joueur (gauche/droite)
- Tir laser avec effets sonores
- Apparition continue d’ennemis
- Ennemis avec vitesse aléatoire
- Collisions laser/ennemi et ennemi/joueur
- Score dynamique
- Système de vies
- Musique de fond
- Écran Game Over

---

## Technologies utilisées

- **Python 3.x**
- **Turtle**
- **Pygame**
- **Random**
- **Time**

## Installation

### 1. Installer Python

https://www.python.org/downloads/

### 2. Installer les dépendances

```bash
pip install pygame
```

### 3. Lancer le jeu

```bash
python space_invaders.py
```
